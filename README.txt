========================================================================
       Antigravity 便携式增强工具箱 (全离线、免配置、自包含绿色包)
========================================================================

本离线包专为 Google Antigravity 2.x 设计，已完整内嵌便携版 Node.js 运行环境与
两个核心工具的全部离线资源，可整包复制到任何 Windows 电脑上直接双击使用。

------------------------------------------------------------------------
一、项目来源与原始开源地址
------------------------------------------------------------------------
1. Antigravity 对话上下文查看器与 Token 用量看板 (Context Viewer)
   - 项目地址: https://github.com/elviscjn-cjn/antigravity-context-viewer
   - 社区鸣谢: Linux.do 社区 (@23375, @anyu0804, @Jia131313 等)
   - 本地目录: packages/viewer/ (v0.8.3)

2. Antigravity Pulse (能量胶囊)
   - 项目地址: https://github.com/akelabs/antigravity-pulse
   - 开发团队: Ake Labs (@akelabs / @codavidgarcia)
   - 本地目录: packages/pulse/ (v1.3.1)

------------------------------------------------------------------------
二、核心组件与功能说明
------------------------------------------------------------------------
1. [内置运行环境] bin/node/node.exe (Node.js v26.4.0 便携版，免全局安装)
2. [即时热重载引擎] bin/hot-reload.js (基于 CDP 毫秒级重载窗口，免杀进程)
3. [上下文与Token看板] packages/viewer/
   - 挂载位置：顶部顶栏与大抽屉面板
   - 核心功能：52周Token热力图、生成速度/TTFT/用量审计、API账单折算、
              系统提示词精简(0至4档)、上下文上限解锁(PR #3)、界面汉化切换
4. [实时能量胶囊] packages/pulse/
   - 挂载位置：输入框底部紧邻 Turbo 按钮
   - 核心功能：实时 tok/s 速度、莫兰迪容量跑道胶囊、5小时共享配额重置倒计时、
              临界压缩预警(>=85%)、React Fiber 多会话独立隔离

------------------------------------------------------------------------
三、工具安装与卸载脚本 (双击即可运行)
------------------------------------------------------------------------
【推荐组合】
- 一键安装全部工具.bat
  -> 自动按照黄金顺序（先 Context Viewer，后 Pulse）一键完成两个工具的注入与重启。
- 一键卸载全部工具.bat
  -> 自动逆序（先剥离 Pulse，后还原 Context Viewer）完全恢复为官方原版 app.asar。

【独立控制】
- 1-安装-ContextViewer(上下文查看器).bat  -> 单独安装/更新 Context Viewer
- 1-卸载-ContextViewer(上下文查看器).bat  -> 单独卸载 Context Viewer 并还原备份
- 2-安装-Pulse(能量胶囊).bat             -> 单独安装/更新 Pulse 能量胶囊
- 2-卸载-Pulse(能量胶囊).bat             -> 单独精确剥离 Pulse 能量胶囊

[重要提示：性能与连带卸载说明]
* 1. 性能提示 (Context Viewer 可能会导致卡顿)：
  Context Viewer (上下文查看器) 需高频扫描会话历史与计算长周期 Token 消耗，
  在会话较长或某些设备上可能会引起 Antigravity 客户端出现卡顿、掉帧或响应延迟。
  如遇明显卡顿，建议使用「1-卸载-ContextViewer.bat」卸载查看器，仅保留更轻量的 Pulse。

* 2. 为什么单独卸载 Context Viewer 会导致 Pulse 连带失效？
  原因：两者均修改同一核心文件 app.asar。执行「1-卸载-ContextViewer」时，底层
  机制会将 app.asar 整包还原为安装前备份的官方纯净原版，从而覆盖掉 Pulse 钩子。
  解决方案：
  - 若需完全卸载恢复纯净官方原版：优先运行「一键卸载全部工具.bat」。
  - 若仅需卸载 Context Viewer 并保留 Pulse：在执行卸载 Context Viewer 后，
    只需再次双击「2-安装-Pulse(能量胶囊).bat」（约20毫秒完成重挂），即可恢复胶囊。

四、本地化增强与快捷工具 (支持免重启即时热重载)
------------------------------------------------------------------------
- 【汉化】开启客户端界面中文.bat
  -> 独立纯净汉化 (方案 A)，零 ContextViewer 残留，内置自动热重载，秒级刷成中文！
- 【汉化】关闭客户端界面中文(恢复英文).bat
  -> 精准剥离汉化补丁，恢复原生英文，保留 Pulse 能量胶囊并即刻热刷新。
- 【标题】开启自动中文会话标题.bat
  -> 改写内核提示词，让后续新建的对话自动生成简短中文标题 (4至10字)。
- 【标题】关闭自动中文会话标题(恢复英文).bat
  -> 恢复为官方原版英文会话标题规则。
- 【工具】即时热重载窗口(免重启刷新).bat
  -> 任何时候想刷新前端界面（如切换配置后），双击即可在 1 秒内免重启热刷新所有活动窗口。

------------------------------------------------------------------------
五、上下文上限解锁与切换脚本 (双击即可运行)
------------------------------------------------------------------------
官方默认本地自动压缩阈值为 256,000 Tokens (256K)。使用以下脚本可随时切换：
- 【上下文】0-查看解锁状态.bat
  -> 查看当前电脑 language_server.exe 的解锁状态与备份文件信息。
- 【上下文】1-解锁为1M动态模式(跟随模型上限).bat
  -> 突破 256K 限制，直接跟随模型物理上限 (1,000,000 / 983,040)，自动重启生效。
- 【上下文】2-解锁为512K固定模式.bat
  -> 将自动压缩阈值固定翻倍至 512,000 Tokens，自动重启生效。
- 【上下文】3-恢复官方原版256K.bat
  -> 100% 无损还原为官方原版二进制 (256K 阈值)。

------------------------------------------------------------------------
六、跨电脑使用方法
------------------------------------------------------------------------
1. 将本文件夹「Antigravity-Tools-Portable」打包为 zip 或直接复制到 U 盘 / 网盘。
2. 拷贝到另一台 Windows 电脑的任意位置（如桌面或 D 盘）。
3. 确保该电脑已安装 Antigravity 客户端（默认路径位于 AppData\Local\Programs\antigravity）。
4. 直接双击「一键安装全部工具.bat」，约几秒钟后客户端自动重启，即可直接体验！
   * 目标电脑不需要提前安装 Node.js，不需要安装 Git，也不需要联网下载任何外部文件。
